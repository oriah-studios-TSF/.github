# oriah.studios

**Web applications and systems built by Oriah Studios.**

oriah.studios is an independent software studio focused on building practical web applications, digital platforms, and systems.

We build projects from the ground up, from the application logic and database layer to the interface and supporting infrastructure.

## What We Build

- Web applications
- Backend systems and APIs
- Digital platforms
- Internal tools and systems
- Experimental software projects

We focus on understanding how systems work beneath the surface and building them piece by piece.

- Clear architecture
- Practical functionality
